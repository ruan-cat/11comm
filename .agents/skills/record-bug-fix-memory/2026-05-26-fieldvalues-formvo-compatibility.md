# 2026-05-26 FieldValues 与 FormVO 类型兼容性事故

## 1. 问题现象

88 个使用 `as FieldValues` 的文件中仅 2 个报 TS 错误，现象无法完全解释。

## 2. 实际根因

TypeScript 编译器对交叉类型的兼容性检查存在不一致行为，可能与 vue-tsc 特殊处理有关。大部分 FormVO 类型恰好满足 `FieldValues` 的结构约束，但少数类型因缺少索引签名而不兼容。

## 3. 关键误导点

误认为所有 FormVO 都需要索引签名，实际上大部分不需要。也容易误归因为其他类型修复的连带效应。

## 4. 有效修复

仅为报错的 2 个类型添加索引签名 `[key: string]: any`。

## 5. 验证方式

`pnpm typecheck` 通过，FieldValues 相关错误消除。

## 6. 后续约束

新增 FormVO 类型建议添加索引签名以保持一致性。在统计类型错误修复结果时，要明确区分目标错误和已有无关错误，避免把已有错误算入修复失败范围。
