# 2026-05-26 Nitro 接口测试环境配置事故

## 1. 问题现象

Nitro 接口测试无法在 jsdom 环境中运行，缺少数据库连接能力。

## 2. 实际根因

jsdom 环境缺少 Node.js 原生模块和数据库连接，后端接口测试需要独立的 node 环境。

## 3. 关键误导点

误认为可以在 jsdom 中测试后端接口。前端组件测试和后端接口测试的运行环境需求完全不同。

## 4. 有效修复

配置 `vitest.config.ts` 条件切换（`--node` 参数区分环境），为 node 环境配置 Neon 数据库连接。

## 5. 验证方式

`pnpm test:nitro` 命令成功运行接口测试。

## 6. 后续约束

后端接口测试必须使用 node 环境；前端组件测试继续使用 jsdom。两种测试不要混在同一个 vitest 配置中。
