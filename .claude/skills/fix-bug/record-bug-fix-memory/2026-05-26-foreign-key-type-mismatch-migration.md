# 2026-05-26 外键约束类型不匹配导致迁移失败事故

## 1. 问题现象

`drizzle-kit migrate` 命令失败，报错外键约束类型不匹配（text vs uuid）。

## 2. 实际根因

初始迁移文件中 `ownerId` 被定义为 text 类型，但目标字段 `hp_owners.id` 是 uuid 类型，PostgreSQL 不允许跨类型外键。

## 3. 关键误导点

误认为可以通过新迁移文件修复旧迁移错误。实际上 Drizzle 要求迁移按顺序应用，旧迁移中的类型错误无法被后续迁移覆盖。

## 4. 有效修复

删除错误的迁移文件目录，修正 Schema 定义中的字段类型，重新生成初始迁移。

## 5. 验证方式

`pnpm db:migrate` 成功；使用 Neon MCP 工具查询数据库表，确认外键约束存在且类型一致。

## 6. 后续约束

Schema 修正前必须审查外键关联字段的类型一致性。开发环境迁移失败时优先重置迁移历史（删除迁移目录重新生成），而非试图用新迁移修复旧迁移。
