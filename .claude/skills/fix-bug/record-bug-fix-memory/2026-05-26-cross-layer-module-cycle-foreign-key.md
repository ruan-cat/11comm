# 2026-05-26 跨层级模块循环依赖导致外键缺失事故

## 1. 问题现象

`hpInvoices.payment_id` 缺少物理外键约束，数据完整性无法在数据库层保证。

## 2. 实际根因

`house-property.ts`（Level 2）需要引用 `expense.ts`（Level 4）中的支付记录，直接添加外键会导致循环依赖。

## 3. 关键误导点

误认为可以直接添加外键引用，忽略了模块分层架构约束。

## 4. 有效修复

将 `hpInvoices` 表迁移至 `expense.ts` 模块，或创建新的 Level 5 `finance-archive` 模块来打破循环。

## 5. 验证方式

数据库层验证外键约束存在；模块依赖图无循环。

## 6. 后续约束

模块依赖必须遵循分层架构，低层级模块不得引用高层级模块。跨层级引用需要重新组织模块结构，而非强行添加外键。
