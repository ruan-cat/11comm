# 认证系统故障排查手册

## 1. 常见错误及解决方案

### 1.1 认证失败

**症状：** 登录失败，返回错误信息

**可能原因：**

1. 用户名或密码错误
2. 账户未激活
3. Neon Auth 服务不可用

**排查步骤：**

1. 检查 Neon Auth 服务状态
2. 确认用户凭证正确
3. 查看服务器日志

### 1.2 Token 验证失败

**症状：** 401 错误，提示"Token 无效或已过期"

**可能原因：**

1. Token 已过期
2. Token 被篡改
3. Cookie 密钥不匹配

**解决方案：**

1. 重新登录获取新 Token
2. 检查 NEON_AUTH_COOKIE_SECRET 配置
3. 清除浏览器 Cookie 后重试

### 1.3 OAuth 登录失败

**症状：** OAuth 登录跳转后返回错误

**可能原因：**

1. OAuth 配置不正确
2. 回调 URL 不匹配
3. 用户拒绝授权

**排查步骤：**

1. 确认 OAuth 回调 URL 与配置一致
2. 检查 Client ID 和 Secret 是否正确
3. 查看 OAuth 服务商错误信息

## 2. 日志分析

### 2.1 认证日志

认证相关日志前缀：

- `[Auth]` - 认证流程
- `[OAuth]` - OAuth 流程
- `[JWT]` - Token 验证

### 2.2 日志级别

| 级别  | 说明                 |
| ----- | -------------------- |
| ERROR | 认证失败、服务错误   |
| WARN  | 权限不足、配置警告   |
| INFO  | 登录登出、Token 刷新 |

## 3. 调试技巧

### 3.1 开启详细日志

```typescript
// 在代码中设置
process.env.OAUTH_SHOW_ERROR_DETAILS = "true";
```

### 3.2 检查 Token

在浏览器开发者工具中：

1. 打开 Application/Storage 面板
2. 查看 Cookie 中的 `authorized-token`
3. 使用 jwt.io 解码查看内容

### 3.3 网络请求

使用浏览器开发者工具：

1. Network 面板
2. 筛选 XHR/Fetch 请求
3. 查看请求和响应详情

## 4. 性能问题

### 4.1 Token 刷新

如果 Token 刷新频繁：

- 检查 Token 过期时间配置
- 考虑增加 Token 有效期

### 4.2 频率限制

触发频率限制时：

- 等待重试时间
- 检查是否有异常请求
- 考虑调整限制阈值

## 5. 安全问题

### 5.1 Token 泄漏

如果怀疑 Token 泄漏：

1. 立即让用户重新登录
2. 检查服务器日志
3. 考虑实现 Token 撤销功能

### 5.2 权限提升

发现权限异常：

1. 检查角色配置
2. 审查 RLS 策略
3. 审计权限变更日志

## 6. 联系支持

如果以上方法无法解决问题：

1. 收集日志和错误信息
2. 记录复现步骤
3. 联系技术支持团队
