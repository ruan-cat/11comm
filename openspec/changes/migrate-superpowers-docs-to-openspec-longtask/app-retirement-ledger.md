### 可复跑扫描命令

task437 的 rows/unique/exact/fallback/diagnostic/apiOnly 统计使用 URL endpoint 定义口径，不按 method+url 展开。`/test/params` 在代码里同时支持 GET/POST，但在本台账中仍只计作 1 个 diagnostic URL。

```powershell
$pattern = 'url:\s*[''"]([^''"]+)[''"]'
$app = Get-ChildItem apps\app\server\modules -Recurse -Filter endpoints.ts | ForEach-Object {
  Select-String -Path $_.FullName -Pattern $pattern -AllMatches | ForEach-Object {
    $_.Matches | ForEach-Object { $_.Groups[1].Value }
  }
}
$api = Get-ChildItem apps\api\server\modules -Recurse -Filter legacy-endpoints.ts | ForEach-Object {
  Select-String -Path $_.FullName -Pattern $pattern -AllMatches | ForEach-Object {
    $_.Matches | ForEach-Object { $_.Groups[1].Value }
  }
}
$diagnostic = $app | Where-Object { $_ -like '/test*' } | Sort-Object -Unique
$exactOld = $app | Where-Object { $api -contains $_ } | Sort-Object -Unique
$fallback = $app | Where-Object { ($api -notcontains $_) -and ($_ -notlike '/test*') } | Sort-Object -Unique
$apiOnly = $api | Where-Object { $app -notcontains $_ } | Sort-Object -Unique
[PSCustomObject]@{
  appRows = $app.Count
  appUnique = ($app | Sort-Object -Unique).Count
  apiRows = $api.Count
  apiUnique = ($api | Sort-Object -Unique).Count
  exactOldSource = $exactOld.Count
  fallbackOnly = $fallback.Count
  diagnostic = $diagnostic.Count
  apiOnly = $apiOnly.Count
  apiOnlyPaths = ($apiOnly -join ', ')
  diagnosticPaths = ($diagnostic -join ', ')
} | Format-List
```

不得据此删除、移动、归档、重命名或清空 `apps/app/server`、`apps/admin/server` 或 `D:\code\ruan-cat\01s-11comm-app`。本文所有只读/查询行的 `retirementDecision` 都保持 `keep-source`，所有写入口行保持 `blocked`，严禁把任何行升级为 `delete-candidate`。

## 默认值与字段语义

- `batchId` 固定为 `task-306-baseline`，表示本轮只做台账物化，不做 runtime 迁移或生产采证。
- `sourceKind` 固定为 `route-inventory-app-legacy-registry`，`sourcePath` 指向 `route-inventory.md#app-legacy-explicit-registry`。
- `coverageKind=old-path-exact-covered` 只表示 `apps/api` 侧已有 exact legacy registry 行，不代表调用端、浏览器、DB、fallback 或退役完成。
- `manifestAllowlist=app-shadow-allowlist` 只表示当前 manifest/allowlist 可被 app shadow 识别；写入口统一为 `blocked-for-execution`。
- 只读/查询行默认 `dataSourceStatus=partial-or-mixed`、`dbReadinessEvidence=READY_CONFIGURED-only`、`fallbackEvidence=pending-shadow-off-or-fallback-drill`、`writeReadRollbackEvidence=not-applicable-readonly-or-query-compatible`、`retirementDecision=keep-source`。
