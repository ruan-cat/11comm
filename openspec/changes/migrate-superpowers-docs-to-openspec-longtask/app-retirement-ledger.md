# 2026-05-25 app legacy 退役台账 baseline

## 范围 Scope

本版只覆盖 `route-inventory.md` 的 `App Legacy Explicit Registry` 中 21 个显式 app legacy endpoint：`fee` 12 个、`repair` 7 个、`floor` 2 个。本文是 task 306 的逐 endpoint ledger/candidate 行 baseline，用于把 app 端已显式注册的旧路径、方法、调用端、目标 adapter、manifest/allowlist、guard/fallback、数据源状态、浏览器或 HTTP 证据和退役判断先物化成稳定 artifact。

## 禁止误判 No-go

本项只完成 §3A app 端 21 行 baseline，不代表 §5 old-service retirement candidate 清单完成；不代表 admin endpoint、client-only gap、server-only endpoint、debug/test/edge、upload/R2 或 guarded write 全量覆盖；不代表 `DB_READY`、真实库样本、write/read/rollback、shadow-off/fallback 复验、生产三端双环境证据或旧服务退役门禁通过。

不得据此删除、移动、归档、重命名或清空 `apps/app/server`、`apps/admin/server` 或 `D:\code\ruan-cat\01s-11comm-app`。本文所有只读/查询行的 `retirementDecision` 都保持 `keep-source`，所有写入口行保持 `blocked`，严禁把任何行升级为 `delete-candidate`。

## 默认值与字段语义

- `batchId` 固定为 `task-306-baseline`，表示本轮只做台账物化，不做 runtime 迁移或生产采证。
- `sourceKind` 固定为 `route-inventory-app-legacy-registry`，`sourcePath` 指向 `route-inventory.md#app-legacy-explicit-registry`。
- `coverageKind=old-path-exact-covered` 只表示 `apps/api` 侧已有 exact legacy registry 行，不代表调用端、浏览器、DB、fallback 或退役完成。
- `manifestAllowlist=app-shadow-allowlist` 只表示当前 manifest/allowlist 可被 app shadow 识别；写入口统一为 `blocked-for-execution`。
- 只读/查询行默认 `dataSourceStatus=partial-or-mixed`、`dbReadinessEvidence=READY_CONFIGURED-only`、`fallbackEvidence=pending-shadow-off-or-fallback-drill`、`writeReadRollbackEvidence=not-applicable-readonly-or-query-compatible`、`retirementDecision=keep-source`。
- 写入口行默认 `manifestAllowlist=blocked-for-execution`、`targetStatus=blocked-for-execution`、`dataSourceStatus=blocked-for-execution`、`writeReadRollbackEvidence=blocked-for-execution`、`retirementDecision=blocked`。
- `browserHttpEvidence` 是 task 306 的浏览器/HTTP 证据字段，同时承接 phase7 ledger 中 `browserEvidence` 的含义；本 baseline 未新增生产浏览器或生产 HTTP 采证。
- `appsApiTarget` 和 `targetHandlerAdapter` 只描述当前代码中的目标定义和 adapter 入口，不表示生产切流、真实库样本或 shadow-off/fallback 完成。

## 排除项与 keep-source 边界

- client-only gap 四条不纳入本 baseline：`/app/itemRelease.queryFinishItemRelease`、`/app/purchase/updatePurchaseApply`、`/app/purchaseApply.listAuditHistoryOrders`、`/app/resourceStore.listAllocationStoreHisAuditOrders`。这些路径需要单独保持 gap/blocked 口径，不得因 21 行 ledger 被视为已覆盖。
- server-only、mock、test、debug 路径不纳入本 baseline。`contact`、`test`、`foo*`、`login.ts`、diagnostic/mock-only 或 dynamic route 的证据不能并入这 21 行。
- fallback-only 的其余 app paths 不纳入本 baseline。`route-inventory.md` 当前记录 `apps/app` 有 214 个 unique legacy paths，扣除 21 个显式 `apps/api` definitions 后，其余 193 个 `/app/**` 或 `/callComponent/**` 仍按 fallback-proxy 或待归类口径保守记录。
- admin fee/payment/report 证据不得升级 app fee/payment legacy。admin canonical route、admin H5、admin manifest、HTTP 200、Vitest、contract 或 local ready 只能作为对应 admin 侧证据，不能替代 app H5、app legacy envelope、fallback/shadow-off、Neon main `DB_READY`、真实库样本或写入读回回滚。
- §5 task 339-341 仍保持未完成。本 artifact 不是 old-service retirement candidate 清单，不是全量 retirement ledger，也不是目录级退役评审输入的完成证明。
