# 旧内置 Nitro 退役证据矩阵

本文是 `migrate-superpowers-docs-to-openspec-longtask` §7 的目录/文件组级证据矩阵。它延续已归档 `assess-legacy-nitro-server-retirement/retirement-evidence-matrix.md` 的保守状态机，但当前矩阵是 active longtask 的 canonical evidence 入口。

## 字段说明

| 字段                       | 含义                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------- |
| `directoryPath`            | 被评审的目录、配置、脚本或文件组                                                        |
| `fileGroup`                | 文件组分类                                                                              |
| `currentDependency`        | 当前仍存在的依赖、阻断或待确认项                                                        |
| `targetReplacement`        | `apps/api` 或前端侧替代能力                                                             |
| `configScriptEvidence`     | config、package script、generator、docs 或调用端证据                                    |
| `testBuildEvidence`        | 已运行或待运行的测试、typecheck、build、OpenSpec 校验                                   |
| `runtimeEvidence`          | 页面 Network、HTTP gate、health/ready、生产 evidence                                    |
| `fallbackOrShadowEvidence` | fallback/shadow-off/legacy dispatch 证据                                                |
| `dbR2SeedEvidence`         | DB、seed、R2、write/read-back/rollback/residual 证据                                    |
| `dryRunEvidence`           | 隔离 rename/delete dry-run 证据                                                         |
| `rollbackNote`             | 回滚或恢复方式                                                                          |
| `retirementDecision`       | `protected`、`blocked`、`keep-source`、`not-candidate-but-unused` 或 `delete-candidate` |
