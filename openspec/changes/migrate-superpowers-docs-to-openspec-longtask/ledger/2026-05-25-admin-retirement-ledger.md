# 2026-05-25 admin 退役候选台账 baseline

本文是 task544 的 admin-only 退役候选台账 baseline。它只把后台 160 个 admin canonical endpoint 的退役字段物化成可追溯记录，不代表全局 old-service retirement candidate 清单完成，也不代表任何旧服务目录可删。

基础来源是 `route-inventory-details.csv.md` 的第一个 CSV 区块。该区块已经逐 endpoint 落行 160 条 admin canonical route，并记录 `routeFile`、`runtimeKey`、`legacyPath`、`canonicalPath`、`method`、`ownerModule`、`legacySource`、`manifestPhase` 与 `manifestStatus`。本文件不重复复制这 160 条基础身份行，避免后续 route inventory 与 ledger 双写漂移；每一条基础行都按下方确定性 overlay 投影成一条 retirement ledger 行。

本台账的固定字段投影如下：`batchId` 固定为 `task544-admin-retirement-ledger-2026-05-25`；`ownerRole` 固定为 `admin`；`sourcePath` 来自基础行 `routeFile`；`oldPath` 来自基础行 `legacyPath`；`appsApiTarget` 与 `targetRoute` 来自基础行 `canonicalPath`；`method` 来自基础行 `method`；`runtimeManifest` 来自基础行 `manifestPhase` 与 `manifestStatus`；`businessPath` 和 `callerEvidence` 优先引用 task521 caller mapping artifact，无法匹配时按 task542、task515 或本文件特殊行写入保守原因。

## 退役边界

- 本文件只关闭 admin 逐 endpoint ledger 字段物化，不关闭 `task804`、`task805`、`task806` 的全局 old-service retirement candidate、全局 ledger 或跨类别覆盖要求。
- 本文件不关闭 `task540` 的逐页面 Chrome Network 缺口，也不关闭 `task541` 的 detail/create/update/delete 写入读回回滚缺口。
- 本文件不关闭 `task809` 的退役评审前 fallback/shadow-off 复验，也不把 task809 三端双环境记录升级为目录退役许可。
- 本文件不解除 `apps/admin/server` 保护，不进入删除、移动、归档、重命名或清空；所有 admin 行的退役判断只能是 `keep-source`、`blocked` 或保守排除，严禁写成 `delete-candidate`。
- 生产 Neon main 仍只有 `READY_CONFIGURED-only` 级别证据，不得写成生产 `DB_READY`；真实库样本、真实写入、read-back、rollback、cleanup 与 residual check 仍按对应未完成任务继续阻断。
