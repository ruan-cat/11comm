# 旧 Nitro Server 退役证据矩阵

本矩阵是 `assess-legacy-nitro-server-retirement` 的执行证据。它只用于评审 `apps/admin/server` 与 `apps/app/server` 是否具备进入删除候选的条件，不授权直接删除、移动、归档、重命名或清空任何旧 server 目录。

## 字段说明

| 字段                 | 含义                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------- |
| `scope`              | admin、app、api-fallback、openspec 或 dry-run                                           |
| `sourcePath`         | 当前被评审的旧目录、文件组、配置或 endpoint 组                                          |
| `currentDependency`  | 当前仍存在的依赖或阻断                                                                  |
| `targetReplacement`  | 目标替代方案或承接位置                                                                  |
| `callerEvidence`     | 调用端、脚本、配置、mock 或测试证据                                                     |
| `testBuildEvidence`  | 已运行或待运行的验证命令                                                                |
| `fallbackEvidence`   | fallback/shadow-off/legacy dispatch 证据                                                |
| `dbWriteEvidence`    | DB、write/read-back/rollback/R2 证据                                                    |
| `retirementDecision` | `protected`、`blocked`、`keep-source`、`not-candidate-but-unused` 或 `delete-candidate` |
| `rollbackNote`       | 回滚或恢复方式                                                                          |

## 当前判定

截至本矩阵创建时，`apps/admin/server` 与 `apps/app/server` 目录级 `retirementDecision` 均为 `protected`。没有任何目录级条目可以写成 `delete-candidate`。
